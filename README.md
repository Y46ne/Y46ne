### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Pushpin.png" alt="Pushpin" width="25" /> Projets Clés

- **Plateforme Web INNOVENCIA** : Refonte complète en SPA Vue.js 3, API REST PHP et SQLite sur hébergement IONOS. Auth JWT et optimisation des performances.
- **Flight Manager Mobile** : Application Flutter connectée à un backend Python/Flask avec API REST. Gestion des vols, CRUD administrateur et intégration de cartes.
- **League of Legends Explorer** : Single Page Application (Vue.js) consommant l'API de Riot Games avec filtres dynamiques et persistance locale des données.
- **Plateforme Web d'Assurance** : Application de gestion développée en équipe avec Python, Flask et SQL. 
- **Système de Gestion de Bibliothèque** : Application desktop Java/JavaFX et JDBC. Gestion complète de l'inventaire en base de données.
- **Systèmes de Jeu Roblox (Luau)** : Frameworks modulaires (POO), réplication réseau optimisée (RemoteEvents), persistance de données (DataStore) et intégration de mécaniques de mouvement avancées.
